БЛОК: Главная идея PAGER уже реализована
Надзаголовок:
человек → условия связи → сообщение
Главный заголовок:
Правила видны до начала разговора.
Сегодня цифровое общение начинается с доступа: человек получает возможность написать или позвонить, а правила взаимодействия формируются уже после или вообще отсутствуют.
PAGER меняет этот порядок — сначала выбирается формат связи, затем начинается диалог.
Горизонтальные карточки:
Заголовок:
Три изменения в коммуникации
01. Общение начинается с выбора
Текущая модель:
контакт → доступ → общение
Новая модель PAGER:
запрос → выбор формата → общение
Новая модель позволяет начинать связи без немедленного раскрытия личного пространства.

02. Один профиль больше не подходит всем
Сегодня один цифровой профиль объединяет все отношения человека — личные, рабочие и новые знакомства.
PAGER создает разные способы представления себя для разных типов связей.

03. Правила становятся частью общения
Сегодня правила общения существуют внутри настроек, а не внутри самой связи.
PAGER делает правила частью самой связи: кто видит профиль, какие способы общения доступны и насколько долго действует доступ.

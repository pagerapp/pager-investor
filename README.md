# PAGER — инвестиционная страница

Одностраничник для раннего раунда. Mobile-first, без зависимостей и сборки:
чистый HTML + CSS + vanilla JS.

```
pager-investor/
├── index.html          вся разметка + RU-тексты, EN в data-en
├── css/style.css       дизайн-система и все секции
├── js/app.js           сторискроллинг, i18n, ревилы, курсор
├── assets/img/         оптимизированные медиа (3.6 МБ на всю страницу)
└── serve.py            локальный статик-сервер для превью
```

Локальный просмотр:

```bash
python3 pager-investor/serve.py
```

Затем открыть `http://127.0.0.1:4321`. Деплой — выкладка папки как есть на любой
статик-хостинг (Netlify / Vercel / Cloudflare Pages / nginx). `serve.py` в
продакшене не нужен.

## Концепция: «вы смотрите через профиль»

Главный тезис продукта — один человек раскрывается по-разному разным людям.
Страница не описывает это словами, а проделывает с посетителем.

**Порог.** До hero страница спрашивает: кем вы приходите — Личное, Работа,
Гость, Альтер эго. Выбор запоминается на сессию; при повторном заходе порог
не показывается. Можно пропустить («просто листать») — тогда линза Работа.

**Линза.** Выбранный профиль задаёт `data-profile` на `<html>` и переменную
`--lens`. От неё зависят: акценты и хайрлайны, граница в hero-вордмарке,
курсор, шторка перехода, HUD, узлы roadmap. Переключатель живёт в HUD
(на мобильном — нижняя панель, на десктопе — плашка под шапкой) и продублирован
в блоке 02.

**Живая карточка.** В блоке 02 — карточка «так вас видит этот человек»:
аватар, имя, описание, шесть тумблеров возможностей и срок связи. Всё
переключается вместе с линзой. Аватары — реальные кадры из приложения
(один и тот же человек в четырёх предъявлениях).

**Гостевая линза считает время.** Выбрав «Гость», посетитель видит таймер
24 часа, сжатые примерно до двух минут. По истечении карточка закрывается
и предлагает продлить. Инвестиционный контент при этом никогда не прячется —
меняется только то, *через что* его читают.

## Что сделано, чтобы это не было шаблоном

Каждый блок имеет свою композиционную схему, а не повторяет
«надзаголовок → заголовок → лид → два абзаца»:

| # | Блок | Схема |
|---|---|---|
| — | Порог | сплит: вопрос слева, четыре выбора справа |
| — | Hero | гигантский вордмарк PAGER как архитектура, телефон перед ним, граница-хайрлайн делит букв |
| 01 | PAGER ID | одна идея на экран: огромный моноширинный ID + три хайрлайн-факта |
| 02 | Профили | интерактивный сплит: селектор + живая карточка |
| 03 | Мультипрофиль | пин на 430vh, четыре кадра |
| 04 | 24 часа | призрачная цифра-подложка, заголовок поверх, шаги списком |
| 05 | Статус | три колонки: сделано / в работе / скрины |
| 06 | Бизнес-модель | B2C сплошной плашкой, B2B пунктиром |
| 07 | Roadmap | горизонтальный пин с HUD (десктоп), вертикальный таймлайн (мобильный) |
| 08 | Раунд | крупный тип, список направлений, milestone |

Тексты ТЗ сокращены примерно вдвое: смысл и запреты сохранены дословно,
абзацы сжаты в ударные строки. Заголовки несут нагрузку, а не подводки.

## Визуальный язык

### Палитра

| Токен | HEX | Назначение |
|---|---|---|
| `--bone` | `#EDE9E2` | мастер-фон |
| `--paper` | `#F4F1EC` | блок профилей |
| `--stone` | `#DCD6CA` | блок «24 часа» |
| `--ink` | `#0A0A0B` | типографика и тёмные секции |
| `--lens` | — | **цвет активного профиля**, задаётся через `data-profile` |
| `--lens-txt` | — | производный от `--lens`: на светлом фоне подмешаны чернила |

Цвета профилей: Личное `#20C997`, Работа `#38BDF8`, Гость `#D4C4B7`,
Альтер эго `#FFCE7A`.

Бежевый «Гость» и охра «Альтер эго» на кремовом фоне не проходят по контрасту,
поэтому все текстовые акценты используют `--lens-txt`
(`color-mix(in srgb, var(--lens) 72%, var(--ink))`), а внутри тёмных секций
он равен чистому `--lens`. Заливки, свечения и линии берут `--lens` напрямую.

### Типографика

- **Golos Text 900** — дисплей. Широкий тяжёлый гротеск с честной кириллицей.
  Шкала `.d-1 … .d-4`, tracking от `-0.022em` до `-0.038em`, line-height `0.88–0.98`.
- **Golos Text 400–800** — лиды, текст, карточка.
- **JetBrains Mono 400/500** — надзаголовки, номера секций, даты, PAGER ID,
  таймер, служебные строки. Tracking `0.17em`, uppercase.

Отдельно от шкалы живут два «архитектурных» кегля: вордмарк в hero
(`clamp(112px, 30vw, 540px)`) и цифра 24 (`clamp(150px, 42vw, 520px)`).
Контраст между ними и 11-пиксельным моно — основная фактура страницы.

## Тексты и языки

Русский — источник правды, лежит прямо в разметке. Английский — в атрибутах
`data-en` на тех же узлах; переключатель RU/EN в шапке меняет `innerHTML` без
перезагрузки. Заголовки с переносами помечены `data-split` — JS переразбивает их
на строки после смены языка, чтобы построчный ревил не ломался.

Добавить строку: положить русский текст в узел, английский — в `data-en`.
Если внутри есть `<br>`, добавить `data-split`.

## Что сознательно не сделано (по пометкам «без публикации» из ТЗ)

- PAGER ID не подаётся как «username вместо телефона» — отличие раскрывается
  через систему вокруг него.
- Premium ID показан как будущая модель монетизации, не как главное преимущество.
- В блоке профилей — только условия связи; имена и фото ушли в мультипрофиль.
- Нет формулировок «разные версии вас», «смена личности», «маски».
- Раздел временных контактов не называется «Общение в цифрах»; «24 часа» подано
  как характеристика продукта. Про удаление данных не обещано ничего — только
  «завершить связь».
- Направления бизнес-модели разведены по этапам, а не выложены в один ряд.
- Roadmap показывает продуктовые результаты, а не список функций.

## Что нужно заменить перед публикацией

- `hello@pager.app` в CTA и футере — на реальный адрес или форму.
- `og:image` — на отрисованную превью-картинку 1200×630.
- Даты в roadmap — обновлять при любом сдвиге сроков (устаревшая дата вредит
  сильнее, чем её отсутствие).
